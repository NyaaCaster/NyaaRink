NyaaRink source is licensed under AGPL-3.0; see LICENSE. Corresponding source and build instructions: https://github.com/NyaaCaster/NyaaRink

Native client distributions use Go (BSD-3-Clause), gorilla/websocket (BSD-2-Clause), golang.org/x/crypto and golang.org/x/sys (BSD-3-Clause). Full copyright and license texts are appended at build time from the pinned toolchain and modules. There is no bundled Node.js runtime, .NET runtime or executable packer. The server and legacy client retain their existing Node.js dependencies.

Windows distributions include six unmodified components from Microsoft's official Win32-OpenSSH 10.4.0.0p1-Preview OpenSSH-Win64.zip: sshd.exe, sshd-auth.exe, sshd-session.exe, ssh-shellhost.exe, sftp-server.exe and libcrypto.dll. Original LICENSE.txt and NOTICE.txt are included in full as OPENSSH-LICENSE.txt and OPENSSH-NOTICE.txt, including OpenSSL notices. The publisher marks this Preview non-production ready. Source, hashes and signer pin are in packages/windows-openssh.json. Components retain Microsoft Authenticode signatures. They run on loopback under the explicitly confirmed account without installing or changing the system SSH service. Maintainers must review upstream security updates and publish a newly pinned release; existing sessions are not automatically migrated.

Server and CLI builds include dist/licenses/dependencies.json and dist/licenses/THIRD-PARTY-NOTICES.txt, generated by node scripts/licenses.mjs. Containers include these files and the project LICENSE; Node.js and OS notices remain in their base image locations. React and React DOM license texts are included in production notices. Legacy JavaScript client code is retained for existing sessions and regression coverage; new native downloads do not include it.

Nyaa be with you.
