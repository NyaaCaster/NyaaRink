## 1. 目标与边界

交付经C明确接受、可主动撤销、断网可重连、登录后自动恢复的SSH远程协助服务。本地工作空间研发，在SSH别名macmini对应实例Docker部署。支持REST、CLI和MCP，让人工与AI Agent使用同一访问链路。About中英文沿用项目已有定义，许可证AGPL-3.0。

本轮用户已批准：HTTPS/WSS5116；邀请在接受成功时消费；只有双方主动断开撤权；默认普通账户；明确AI参与告知；登录后自动恢复；旧DB恢复保留有效授权，权威数据缺失冻结；私钥不外发；默认只记录元数据；当前模型完成全流程。

V1不做多租户、RBAC、OAuth、遗留SSE、Web终端、远程桌面、无人确认安装或透明自动提权，不提供任意内网代理。系统支持矩阵按已批准R02冻结，不将“有sshd”当成兼容验收。

## 3. 安全不变量

1. 不通过GET消费邀请；并发接受只能一个成功，丢包重试幂等。
2. 不用TTL、SSH exit、进程或网络状态撤销授权；未兑换邀请与短时票据可以过期，已授权会话不能随之过期。
3. 断开先持久化不可逆撤销，再断流/删活跃秘密；两端清理分别报告。
4. API Key、浏览器身份、设备签名、引导Key与流ticket分权；管理Key不下发C。
5. S严格验证C主机身份，C只连本机已登记回环sshd，不开放任意TCP代理。
6. 数据库恢复不能回退权威；缺失权威/密钥冻结访问但不伪造撤销。
7. 安装提权不等于管理员SSH授权；不删除原有公钥、配置与服务。
8. 所有真实.env、证书/私钥、会话/备份、设备状态不进Git/镜像/日志；发行验签公钥作为公开常量例外。

### P3 连接脚本工作流程（2026-10-22 用户确认补充）

Windows `.bat`、Linux `.sh`作为同一会话连接入口，包含SSH服务准备，无需用户另行下载安装脚本。程序包先按发行标准校验，随后按以下顺序执行：

1. 检测本机SSH服务的实际程序、版本与启动参数及有效能力；取消OpenSSH8.9硬门槛，不自动升级或替换已有服务。已有可用服务复用并保留原配置与授权；能力不足明确报告，不移除安全限制。Windows内置8.6p1从本机实测开始纳入候选矩阵，真实认证、PTY、SFTP及转发限制通过前不宣称兼容。
2. 缺少服务时，本地显示变更并单独征得确认，按需提权安装、启动；已有服务但未启动时，经确认启动。必要时在安装确认中启用sshd系统服务自启动。拒绝、提权失败或安装失败时明确报告，保留等待状态，不绕过确认或自动撤销授权。
3. 安装服务后返回用户确认的目标账户上下文，核验主机身份，配置本次公钥、设备身份和连接程序。默认普通账户；安装提权不授予管理员SSH权限，高权限账户仍须单独明确授权。
   Windows入口按2026-10-22补充确认内置UAC：仅安装/启动与必要的只读sshd配置检查提权，原用户连接程序持续运行；其他管理员凭据不替换SSH目标账户，不提升登录恢复任务。
4. 为该账户设置登录后自动恢复，全部准备成功后建立出站连接并报告ready；部分失败按补偿流程恢复，不虚报上线。

P6下载按钮仍名为“下载连接脚本”；简短说明脚本会检测SSH服务、经确认按需安装启动并配置连接。移除独立的手动SSH安装命令说明区，安装变更与提权确认保留在本机脚本流程。原型位于`.docs/原型/C端页面.html`，已获用户整体审核通过，不计入P阶段完成。
