# P6 C 网页闭环实施计划

2026-10-22，沿用已批准 GUI 原型及连续开发授权。P3–P5 待验收项继续保留。

1. 采用原型已批准的配色、排版、双栏布局；浅色/暗色/系统主题，默认跟随系统，记住用户选择。
2. 接入 Cookie/CSRF 邀请预览、显式接受与幂等重试；无效页面不展示他人会话信息，GET 不消费。
3. 下载连接脚本，简短说明包含 SSH 检测和经确认安装/启动；不恢复单独安装说明区。
4. 通过只读、严格 Origin/Cookie 的 WSS 获取授权与在线状态、实际账户及指标；失联显示待核实，不冒充已撤销。
5. C 主动断开采用二次确认，收到持久化结果再显示撤销；S 主动断开推送最终状态，刷新无效；均提醒删除脚本。
6. 恢复页面通过短时配对码及本机连接程序确认，不用邀请码重新授权。
7. 验证真实浏览器流程、主题、窄屏、键盘、跨站拒绝及撤销刷新。缺少真实 C 系统环境的验收不得由界面测试代替。

涉及 web React/CSS、server 浏览器事件与静态资源、浏览器集成测试。全部文案为实际状态；UI 不显示虚构的账户、连接数量或已清理结果。
