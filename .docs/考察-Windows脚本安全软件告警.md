# Windows 连接脚本安全软件告警考察

日期：2026-10-22。状态：用户已批准 ZIP、明确不改 PS1；P10 已实现并通过本地回归，生产发布状态以验收记录为准。

## 已知事实与结论边界

用户报告 Chrome 下载的 NyaaRink bat 被检测为 Trojan/PS.ShellLoader.c，ID F16933EF5B384A44，并被删除。尚不知道杀毒产品、版本、规则解释及被删除文件的 SHA256；不能将告警直接定性为已证实误报或系统已中毒，也不能用告警中的进程名认定 Chrome 感染。

P10 之前的源码 apps/server/src/artifacts.ts 生成 bat，主体是 UTF-16LE Base64 的 PowerShell -EncodedCommand；其建立私密目录，通过 HTTPS 下载 Node 客户端 ZIP，验证 SHA256、清单及发行签名，然后启动客户端安装。编码为命令行传输实现，未提供代码机密性；但不利于用户直接审阅。编码执行与下载后启动形成与 ShellLoader 类告警相符的候选触发特征，确切命中原因仍需厂商确认。P9 已验证当时的生产包及运行代码，不能替代本次被删除文件的逐字节核对。

客户端还有明确 UAC 的编码 PowerShell 系统准备/检查以及经同意创建的登录恢复任务。仅修改下载外壳不代表全部安装行为已经被安全软件认可。需连同系统准备子进程、任务说明和可见授权说明一起审阅；不得改名伪装、关闭防护、添加排除项、混淆、绕过执行策略或杀软扫描。

## 已批准的交付调整（A19）

Windows 改为透明 ZIP 连接包：包含短小可读的 bat 启动入口、独立 bootstrap.json、本地客户端和便携运行时及验签材料、阅读说明；用户先解压再启动。下载入口保留“下载连接脚本”，描述改为解压后运行。将授权数据与执行代码分离；启动前验证公开发行签名和文件完整性，保留现有 HTTPS、私密状态 ACL、默认普通用户、系统准备才提权和明确同意。

用户已确认改变原单 BAT 下载格式。现 ZIP 内含 start.bat、bootstrap.json、原始签名 client-runtime.zip 和 README.txt，无 PS1；明文 PowerShell 只本地校验与展开，不再由入口下载程序。结构调整不能保证消除检测。

完整离线包的凭据包含短时引导 key；下载响应不得缓存，不能写日志，用户不得分享。解压目录与私密持久运行目录必须分离；现有 bootstrap 到期可补发、接受才消费邀请及仅主动断开撤权语义不变。运行时不需要从网络临时取得可执行代码；安装后的出站 WSS 仍是业务功能。

当前 Ed25519 发行签名是项目自己的完整性/真实性校验，不是 Windows Authenticode 发行者签名。正式代码签名需独立证书与签名流程，也不保证安全软件一定放行；不在本轮擅自购买证书。
