# C端 GUI 审核原型

2026-10-22，第一版，已获用户审核通过。此原型用于追加界面设计，不代表P阶段实现、真实连接或产品验收通过；已批准授权规则不变，P1–P8仍未开始。

## 打开与审核

双击同目录的 `C端页面.html`，使用现代浏览器打开即可。单文件包含全部样式、图标与交互，无外部字体、CDN、接口调用或安装步骤。源码链接仅在手动点击时跳转。

默认跟随系统浅色/暗色主题；可手动切换，选择保存在本浏览器的原型主题设置中。选择“跟随系统”后会响应系统主题变化。浏览器禁止本地存储时，本次打开仍可切换。

顶部“预览场景”提供：收到邀请、接受后等待部署、设备在线、设备意外离线、页面失联、C端主动断开、S端主动断开但本机待清理、无效邀请。接受前需勾选知情说明；接受后才显示可用的脚本按钮。按钮只弹出说明，不生成真实脚本。断开有确认框；页面失联场景不会伪造撤销成功。断开结果提供“模拟刷新”，切换为无有效信息的通用页面。

## 视觉方案

- 浅色：冰蓝背景 `#eef2f8`、白色内容、蓝紫主色 `#6354cb`；暗色：深蓝灰背景 `#141a26`、内容 `#1d2534`、淡紫主色 `#afa0ff`。绿色表示已确认，琥珀色表示等待核实，红色只用于撤销操作。
- 字体使用系统自带字体：Bahnschrift用于品牌和指标，Segoe UI/微软雅黑用于内容，Consolas用于脚本名与命令，无字体下载。
- 桌面左侧说明与本机步骤，右侧固定连接控制；窄屏把控制区移到前面并改为单列。签名元素是两台设备之间的连接线，随连接状态变化；授权状态单独展示，避免误把离线当撤销。
- 所有姓名、账户、目的、时间、指标与清理结果都是固定演示值。原型不读真实系统账户、不发起网络请求、不建立SSH、不安装登录项。

## 审核重点

2026-10-22按用户反馈移除手动SSH安装命令说明区，保留“下载连接脚本”按钮，简短说明脚本检测SSH服务并经确认按需安装、启动和配置连接；顺序已写入SSOT P3。

信息阅读顺序、操作按钮位置、知情说明长度、浅暗主题观感、窄屏布局，以及断网/撤销/待清理状态是否容易区分。视觉方案已获用户确认，纳入P6实现，不能将此HTML直接当作已有后端的产品页面。
