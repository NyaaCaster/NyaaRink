2026-10-22 用户批准 Go 原生 C端、微软官方 OpenSSH-Win64.zip 必需组件与可读 BAT 入口，替代旧 MSI 路线及 C端 Node 分发。当前模型独立实施；沿用连续验证、提交推送与 macmini 部署授权。ZIP 8–15 MB 是估算，以最终实测为准。

## 实施顺序与闸门

1. 隔离验证固定 10.4.0.0p1-Preview 便携 sshd：仅高位回环、自定义配置/主机密钥/授权文件，不注册服务，不改变已有 sshd；验证正常前台多连接、原账户认证、exec/PTY/SFTP和转发拒绝。安全失败不得绕过，普通账户环境缺口如实保留。
2. Go 实现既有 HTTP/WSS 协议、设备签名、授权状态、登录恢复和主动撤销。TLS/主机固定、设备身份、世代、限额均保留。网络故障和退出不撤权。
3. Windows 独立便携 sshd 不覆盖系统服务或用户原公钥；原用户登录恢复，不默认提升远程权限。若实际上需要提权，停在技术闸门报告，不改变权限边界。
4. ZIP 保留 BAT，不新增 PS1；原生验签、官方 ZIP 摘要与 Authenticode 校验，保留许可证，不用 UPX。Linux 保留原批准能力。既有会话不自动迁移或撤销。
5. 原生/协议交叉测试、npm/Python全量验证、签名发行和包体积实测，有证据后更新生产。旧发行继续供原会话使用。
6. 提交推送、独立发行目录、镜像重建、macmini备份重启及TLS/MCP/下载核验；更新SSOT、验收、交接014。A17未测试项如实保留。
