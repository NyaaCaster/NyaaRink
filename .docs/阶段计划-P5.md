# P5 操作入口与 Agent 接入实施计划

2026-10-22，按连续开发授权实施。P3/P4 未完成的真实环境及资源验收继续保留，不以 P5 实现替代。

1. REST、CLI、MCP 共用严格操作 schema 和业务层；管理鉴权、Host/Origin 校验沿用已有入口。
2. exec 先持久化幂等受理记录，后执行；重启仅显示 interrupted，绝不重放。输出仅内存 1MiB/10 分钟，超时/取消只关闭任务。
3. POSIX、PowerShell、cmd 显式 shell；cwd 结构化校验并正确转义，不把调用者路径混为 C 路径。
4. PTY 单次 ticket、WSS 尺寸限制、resize 和关闭；双方撤销及断网关闭原任务。
5. SFTP home 内逐级 lstat、拒绝链接及越界；100MiB 流式上传下载和临时文件原子 rename；MCP 只允许 1MiB 小文件。
6. MCP 无状态 Streamable HTTP 与 stdio 桥；工具说明显式主动断开、默认普通账户、远端输出不可信。
7. 隔离测试幂等、重启、输出限额、取消、路径、鉴权、MCP 工具发现；真实四客户端分别记录，不虚称通过。

涉及 contracts/operations、server operations/工具/路由、cli 与集成测试。正常命令不存正文，不在日志输出凭据。验证、清理、SSOT/交接/memory 及提交推送按共享技能执行。
