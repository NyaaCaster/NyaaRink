# P10 Windows ZIP 连接包改造计划

2026-10-22，用户批准 ZIP 方案并明确不改用 PS1，沿用连续实现、验证、提交与部署授权。当前无模式切换工具，先落盘本计划再实施。

## 交付与约束

- Windows 下载为 ZIP，内含可读 start.bat、独立 bootstrap.json、原始已签名 client-runtime.zip 和 README.txt；不新增 PS1。用户解压一次后运行 BAT，由本机 PowerShell 明文命令展开随包运行时并核对包/清单摘要，再执行既有 Ed25519 验签和安装。不下载程序、不编码 PowerShell、不改执行策略。
- 保留完整原始客户端包，避免重新解压压缩大型发行包；外层 ZIP 使用 store，包不写服务器磁盘。下载最多 2 个并发、每个已鉴权浏览器每分钟 3 次，最多 150 MiB 发行文件。响应 no-store，不记录授权配置；不改变短时引导 key 与幂等重试语义。
- 下载按钮名称保持；Windows 显示解压后运行，断开提示删除包及解压副本。Linux SH 不变。系统准备与检查中的既有明确 UAC 逻辑不在本轮重写，不声称全部程序不使用 PowerShell。
- 保持只在接受时消费、主动断开才撤权、默认普通账户、登录恢复、安装失败保留授权等基线。

1. 调整服务端 Windows 响应、包生成与限额，前端文案/下载扩展名和原型，客户端清理提示。

3. 浏览器验证接受/下载/撤销及 no-store、跨源/CSRF 拒绝，沿用 A17 未测项；全量 tests/typecheck/lint/build 和 Python 验证，清理本轮资源。
