上述是日期快照，不是“永远用latest”。P1 npm ci/类型检查/构建验证后生成package-lock与依赖清单，依赖版本精确可复现。若已批准组合无法构建或安全审查不通过，先报告证据、修订版本决策，不能自行更换语言、协议或降级鉴权。更新安全补丁不要求重新选择产品架构，但须通过原验证闸门。

Node/客户端发行包独立于服务镜像，可在不同架构制作指定平台包；V1仅承诺x64验收。Windows和Linux的原生模块兼容应由各自实际环境测试，不凭“TypeScript跨平台”推断可运行。
