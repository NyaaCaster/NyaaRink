# P4 出站隧道与原生 SSH 实施计划

2026-10-22，依据既有连续实施授权落盘。P3 的发行、本地安装接口已具备，Linux 服务归属检查随本轮补齐；普通 Windows UAC、真实登录及系统矩阵仍未完成。P4 可先基于隔离 SSH 服务实现和验证，P3/P7/P8 的验收闸门继续有效，不以测试替身冒充系统支持。

1. 严格控制消息契约、单次签名挑战、持久 generation；接管旧连接立即关闭旧流。
2. 一次性短期 ticket、独立数据 WSS、回环固定目标、分块背压与双向合计限额。
3. S 逐会话认证、主机固定、exec/PTY/SFTP 和转发限制检查通过后才显示 online。
4. C 前台安装后连接、登录恢复、指数退避、网络退出不撤权；撤销标记关闭本地流并补交清理。
5. 容器私有 Unix socket ProxyCommand、逐会话临时配置与私钥、撤销销毁。
6. 隔离真实 SSH/WSS 集成：重连/接管、错身份、ticket 重放、并发/限流、双向撤销；保留真实 OS/外网待验收项。

涉及 contracts、server tunnel/SSH/proxy、client tunnel/入口、构建及 tests；不改现有系统 sshd 和原公钥。不提前开放 readyz 或部署半成品。验证采用共享 test 技能；结束同步 SSOT、交接和 memory，并按 commit-push 技能提交推送。
