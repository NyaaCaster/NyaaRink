# P13 Windows 连接 ZIP 目录包装计划 🟡

用户要求所有下载连接 ZIP 文件置于一层文件夹，避免直接解压散落。沿用连续修复、验证、提交及部署授权；当前模型独立工作，先落盘计划。

1. 外层 ZIP 全部四个文件使用 NyaaRink-会话ID/ 前缀，名称仅来自经校验的会话 UUID；内层签名发行保持原字节。
2. BAT继续以自身目录定位配置和运行时；说明提示进入目录运行，下载文件名保持不变。
3. 更新发行结构、真实Windows BAT及篡改拒绝、浏览器下载与原生集成夹具；运行typecheck/lint、相关测试和build，清理测试产物。
4. 更新SSOT和技术标准，密钥/diff检查后提交推送，重建双镜像并部署macmini。沿用现有签名发行，无客户端改动不重复签名。
5. 核验真实TLS、镜像revision及生产生成ZIP单根目录/内层摘要；测试只用隔离虚构配置，不创建生产会话。更新验收、交接015及memory，文档收尾提交。
