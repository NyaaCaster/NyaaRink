# OpenSSH兼容底线与本机验证

2026-10-22。对应用户已批准A15，覆盖原R02中OpenSSH8.9统一硬门槛。阶段事实以开发计划SSOT为准。

## 判定原则

取消8.9数字拒绝，不主动升级或替换C端已有SSH服务。继续遵守批准的操作系统矩阵。识别实际服务程序、版本、启动参数和目标账户的有效配置，随后验证真实功能及限制；版本字符串本身不能证明兼容、安全补丁状态或供应商维护状态。

当前业务使用会话独立Ed25519公钥、回环来源限制、`restrict,pty`授权行、exec、PTY和SFTP。没有使用SSH Agent转发或8.9的Agent目的地约束功能，因此没有据此强制8.9的业务依据。不以降版本为由删除公钥限制、关闭主机核验、开放密码或修改全局配置。系统安全更新由C端管理员按供应商维护渠道处理。

## 安装与逐会话准入

1. 检查服务归属、记录版本。Windows当前适配器只接受系统OpenSSH服务的精确程序路径，遇自定义二进制或额外启动参数明确拒绝；不得检查一个程序却连接另一配置的服务。Linux运行服务归属核验仍待补齐。
2. 读取目标账户及回环连接Match上下文的有效配置；优先`-G`，不支持时回退`-T`，必要时走受控本地提权只读检查。检查选定端口、Ed25519、PTY、SFTP、公钥认证及授权文件；不支持则报告并保留等待授权。
3. 从本地可信主机公钥固定回环端身份。安装只追加本会话公钥，保留原行和权限；默认普通账户，高权限另行明确确认。
4. P4获得S端持有私钥的真实连接后，还须验收当前会话公钥认证、exec/PTY/SFTP和禁止转发。未通过前不得作为可操作就绪状态。离线或验收失败不自动撤销授权，也不能用无凭据主机探测代替公钥认证验收。

## Windows本机证据

系统组件为`OpenSSH_for_Windows_8.6p1, LibreSSL 3.4.3`。现有sshd服务运行中，实际端口22142。目标账户有效配置读取成功，支持Ed25519、PTY及SFTP；本机账户为管理员，使用共享管理员授权文件。这仅用于只读调查，未向该文件写入测试公钥。

显式系统检查入口：`tests/openssh-compat-check.ts`。经esbuild打包后运行，使用临时主机密钥、会话密钥和授权文件，独立sshd只监听127.0.0.1随机端口，不停止或改写现有服务。
