# P2 邀请与独立授权权威

2026-10-22，依连续实施授权执行。

实现单写者独立账本（长度帧、HMAC/hash链、fsync、trusted head）、AES-GCM会话密钥包、明确初始化和冻结、SQLite可重建投影及写前一致备份。邀请原子消费与浏览器绑定合为一个事件；设备登记、引导替换、恢复浏览器和撤销均由权威事件驱动。

验证覆盖并发接受、同请求重试/冲突、登记重试/换设备拒绝、旧脚本拒绝、双向撤销幂等、设备签名重放、旧DB恢复重建、新授权保留/撤销不复活、错误主密钥/损坏/缺失/截断账本/head/锁、注入写故障。测试均用独立临时目录并清理；任何SQLite写入前一致备份。
