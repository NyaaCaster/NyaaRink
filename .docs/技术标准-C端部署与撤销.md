# 技术标准：C端部署、自动恢复与撤销

2026-10-22，现行基线A20，对应R02、R03、R05的修订。用户已确认登录后自动恢复，不要求系统无人登录时在线。

## 1. 支持矩阵与交付形态

V1推荐验收范围：Windows11/Windows Server2022及更新的受支持版本x64，Ubuntu22.04/24.04、Debian12/13 x64。2026-10-22 A15取消OpenSSH8.9统一硬门槛；Windows系统组件8.6p1作为首个验证对象，未完成真实验收的组合不得声称支持。功能要求与供应商补丁维护状态分别检查，不将上游版本数字当安全结论。Windows普通本地账户、Linux普通账户为必测；Windows域账户、受限企业策略和其他sshd实现不承诺未经测试兼容。管理员/root另做明确授权路径。

新会话交付 Go 原生单程序，无需 Node/npm/.NET；Linux使用系统 SSH，Windows附微软官方便携 SSH 六组件。S端仍为TS/Node；旧Node会话保留各自运行时，不自动迁移。操作系统目标范围不扩张，实际通过范围见验收记录。

Windows ZIP 所有文件统一放在唯一的 `NyaaRink-会话ID/` 目录内，避免直接解压散落；含可读 start.bat、独立 bootstrap.json、原始签名 client-runtime.zip 和 README.txt；Linux保持.sh。BAT以明文PowerShell在当前用户私密临时目录校验包、清单及可执行文件SHA256，随后由原生程序核验Ed25519清单及所有文件；不新增PS1、不下载程序、不改执行策略。程序移入原用户私密持久目录，按清单摘要分版，不依赖下载目录恢复。

固定工具链与组件见技术依据、packages/windows-openssh.json及go.mod。微软ZIP固定10.4.0.0p1-Preview（非生产就绪），构建核对ZIP SHA256和逐文件微软签名发布者，运行前核对Authenticode信任。六组件原始字节不变，附完整LICENSE/NOTICE及Go/依赖许可；不压壳。发行v2清单含runtime/goVersion、平台、版本和全部文件摘要，离线Ed25519签名，拒绝额外文件、符号链接和异常尺寸。私钥仅保存在私密构建目录，公钥为公开代码常量；真实会话公钥不入Git。Node旧发行仍用原v1标准。

HTTPS及随脚本提供的校验防传输篡改，但同一S源被控制后仍可修改新脚本；不宣称能防恶意S端。TLS链错误、哈希失败、签名错误、发行版本回退均停止安装，保留授权为等待/冻结状态，不静默跳过校验。

## 2. SSH服务准备

Windows现行A20：在原账户下运行独立便携sshd，不检测、安装、升级、启动或更改系统sshd，不修改系统防火墙。程序选择随机高位回环端口，创建独立hostkey/config/authorized_keys，固定实际原账户；Ed25519、PTY、SFTP可用，密码、agent/X11/TCP/streamlocal转发及隧道关闭。主机公钥与回环握手核对，S严格固定身份。端口不可占用时明确失败，不自动更改已绑定身份。

前台sshd先以挂起方式创建，加入kill-on-close Job Object后恢复；关闭或撤销回收该便携进程树，系统sshd不受影响。退出/断网仅暂停在线状态，保留授权，登录后启动独立便携sshd恢复。默认普通账户，高权限目标仍需单独确认。不以调用UAC把远程目标换成管理员。

Linux继续检测实际系统SSH程序、版本、启动参数、配置及服务归属，取消8.9数字门槛；已有服务不自动升级。缺少或停止时，本地显示影响并单独确认后，按需sudo安装/启动openssh-server；不采集上传密码，不放行端口、不覆盖配置或停止其他会话。系统安装器可能产生入站规则需明确告知。绑定本机确认的回环入口和主机公钥；检查Ed25519、PTY、SFTP、授权文件和受限选项，能力不足停止，不静默放宽限制。新原生完整Linux生命周期仍需补验，不能引用旧Node证据为其通过。

A14的Windows系统服务UAC路径仅适用于旧Node会话，历史实现不自动迁移。

## 3. 账户与授权文件

- 默认当前普通账户；检测root、管理员组成员、提升token时明确警示并再次确认，建议改用普通账户。不能仅检查shell是否“以管理员运行”来判定目标SSH权限。
- 普通用户只追加自己的authorized_keys；Unix目录0700、文件0600。行带唯一会话标识，优先 `from="127.0.0.1,::1",restrict,pty`，允许shell/PTY与SFTP，禁止agent/X11/端口转发。安装时验证本机OpenSSH支持这些选项，失败则报告不支持，不静默移除限制。
- Windows私密引导目录、状态目录及文件仅修改 DACL（`AccessControlSections.Access`），禁止用单参数 SDDL 重载隐式修改审计 SACL、所有者或组；不要求 `SeSecurityPrivilege`，不因此提升连接程序。替换已有授权文件时显式复制原 DACL 及继承保护。
- Windows便携会话使用私密会话目录内独立authorized_keys，不写profile或ProgramData的系统授权文件。旧Node会话继续读取系统有效配置。
- 授权文件修改先读取原内容与元数据，原子写回，保留现有行与ACL；Linux同时保留xattr（含POSIX ACL），复制失败停止；拒绝链接及硬链接私密文件。卸载按本次session唯一标识及完整公钥匹配删除，不能删除整个authorized_keys或其他会话的行。
- 登记主机公钥须从可信本地配置/公钥文件取得，并与回环握手核对。S设置hostVerifier或严格known_hosts，不采用ssh2默认auto-accept。密钥轮换需C本地确认并签名更新绑定，网络错误不会自动信任新主机。
- 私钥仅在S，限制来源为回环能减少C原有外网sshd暴露，但同账户或root被攻陷仍可修改授权，超出服务保证。

## 4. 登录后自动恢复

Windows：当前确认账户的“用户登录”计划任务，运行最低权限、无需存储用户密码，`Run only when user is logged on`，使用固定绝对程序路径及sessionId。启动器不含引导Key，不依赖下载脚本，读取私有持久设备状态。安装由该账户确认；若用户为了安装sshd提升过权限，必须返回目标账户上下文创建任务。

Linux：`~/.config/systemd/user/nyaarink-<session>.service`，WantedBy=default.target，Restart=on-failure，禁止自动启用linger，不要求root。用户登录启动其user manager后恢复，注销后是否退出由系统user manager策略决定；无论进程在线与否，授权都不自动撤销。缺少systemd用户管理器时提示不支持，不临时改用cron。

首次安装即启动连接程序；默认有清晰本地状态/停止说明。单设备状态锁避免重复启动。跨启动状态保存设备私钥、实例ID/epoch、会话ID、SSH公钥标记、主机绑定与撤销标记。Windows目录位于当前用户LOCALAPPDATA，Linux遵循XDG_DATA_HOME，0700/最小ACL，不写公共临时目录。

暂时停止进程只暂停在线状态，登录/手动运行后恢复。移除下载bat/sh不卸载程序，也不撤销；双向断开后提示删除下载脚本或 ZIP 及全部解压副本。系统任务/服务名称带sessionId，允许多会话共享运行时但独立凭据和授权行。

## 5. 本地用户命令

程序提供 `status`、`resume`、`resume-browser --code <code>`、`disconnect`、`cleanup`；操作对象均需明确sessionId，多个会话不能默认全部结束。

`disconnect`是明确主动撤销：打印影响并本地确认，先持久化本地revoked，终止流、删除本次授权行与登录项；联网时提交S，离线时保留最小补交凭据，下一次登录仅执行补交和清理，绝不重新提供SSH。`cleanup`仅重试已撤销项清理，不能将有效会话当垃圾删除。

若用户直接删除程序/设备状态，S可能仍显示有效但离线，不能凭此伪称撤销；页面与文档应建议先disconnect再删除。设备丢失时可由S显式撤销旧会话后重新邀请。

## 6. C网页标准

单一邀请/授权状态页，以中文为默认，提供英文关键说明。移动窄屏可读，键盘操作与状态文本完整，不只用颜色传达状态。V1没有管理后台或浏览器终端。

接受前：协助者自报名称（不能暗示已实名认证）、协助目的、账户待本机确认、默认权限、AI告知、网络断开仍保留授权、登录后自动恢复、日志范围、停止方法、源码入口。一个明确的“接受访问”动作，先阅读再点击。

接受后：下载与校验说明、sshd步骤、实际账户与主机绑定状态、授权时长、在线累计、SSH连接数、字节流量、受控操作数、RTT及采样时间；明确“访问已授权”和“设备在线”两项状态，页面离线不推断授权已结束。

断开为独立显著按钮，说明将终止当前操作并撤销本次权限，二次确认防误触；提交后显示真实持久化结果及两端清理进度。断开成功提示删除本次下载脚本或 ZIP 及全部解压副本；刷新无有效会话内容。不把网络超时伪装成断开成功。

## 7. ZIP 连接包资源边界（P10）

Windows 包在内存生成，保持原始签名发行字节不变，不落盘含凭据文件；响应 no-store，不记录配置。单发行文件最大 150 MiB，每实例最多两个在途连接包响应，每个已鉴权浏览器每分钟三次。不信任客户端 X-Forwarded-For 作为限流身份。过期或安装失败保留授权，可按既有未登记设备规则重新下载；下载目录不承担登录恢复。包内配置不可转发或上传公共扫描平台。主动撤销后删除 ZIP 及全部解压副本；删除文件本身不撤权。Windows新包不需要系统SSH准备/UAC；入口和计划任务维护仍使用系统PowerShell/COM，不声称完全不使用PowerShell，也不保证安全软件放行。旧Node会话维持原UAC边界。
